# Fashion Fit

Fashion Fit is a second-hand and vintage clothing sizing demo. It shows how garment measurements can make unfamiliar regional size labels easier to compare, helping shoppers and sellers make more confident choices.

## Try the sizing demo

1. Edit the sample dress's bust, waist and hip measurements, choose centimetres or inches, then select **Record garment sample**.
2. Enter the shopper's body measurements and choose their usual size and size-label region.
3. Review the recommended XS–XL size, compare how the sampled garment is likely to fit, and see approximate US, UK, EU and AU label equivalents.
4. Select **Download fit note** to save a text note that a seller can add to the listing.

The fit estimate uses transparent, illustrative measurement rules and approximate size conversions in the browser. It is a prototype—not a connected AI model, a brand-specific size chart, or a guarantee of fit. Compare each vintage item's actual measurements. No entered measurements are uploaded.

The app is a single `index.html` file with no build step or app dependencies. GitHub Pages serves the public demo at <https://sumi-cpu.github.io/Fashion-Fit/>.
